## Install on Android

1. Open the download link above on your Android phone or board in Chrome.
2. Chrome may warn that this type of file can be harmful. Tap **Download anyway**.
3. Open the downloaded file. If asked, allow **Install unknown apps** for Chrome.
4. Tap **Install**, then open **Trinity Teaching**.

The app works fully offline after installation. It needs Android 6.0 or newer.

## Install on Windows

1. Download **TrinityTeaching-Setup.exe** using the Windows link above.
2. Run it. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. The installer is not code-signed yet.
3. Follow the setup wizard. It creates Desktop and Start menu shortcuts.
4. Open **Trinity Teaching**. It runs full screen; use **Exit** on the home screen to close it, and **F11** to switch full screen on or off.

It needs Windows 10 or 11 (64-bit) and works fully offline.

## Install on Windows

1. Download **TrinityTeaching-Setup.exe** using the Windows link above.
2. Run it. If Windows SmartScreen says "Windows protected your PC", click **More info → Run anyway**.
3. Follow the setup wizard. It adds **Trinity Teaching** to the Desktop and Start menu.

The app opens full screen. **F11** toggles full screen, and the **Exit** button on the home screen closes it.

## Updating

Install the newer APK, or run the newer Windows setup, over the old version. Uploaded presentations are kept.

All versions are listed on the [Releases](https://github.com/aayushbhatta230-ux/trinity-teaching-app/releases) page.
